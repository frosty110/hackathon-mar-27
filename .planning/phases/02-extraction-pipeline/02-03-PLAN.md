    RefMinutesPerMonth = 10_000
)

**Normalize function signature:**

// Normalize applies the reference workload to data and mutates NormalizedMonthlyCost,
// NormalizationAssumptions, CannotNormalize, and CannotNormalizeReason in place.
// Returns the same pointer for chaining.
func Normalize(data *RawPricingData) *RawPricingData
```

**Per-model logic (implement all 6 branches):**

`per-seat`:
- Find the cheapest non-opaque tier that can accommodate RefSeats seats
- If no qualifying tier: `CannotNormalize=true, CannotNormalizeReason="Cannot normalize: all per-seat tiers are Contact Sales"`
- Else: `NormalizedMonthlyCost = tier.BasePrice * RefSeats`
- `NormalizationAssumptions = fmt.Sprintf("%d seats at $%.2f/seat/month (tier: %s). Enterprise/Contact Sales tiers excluded.", RefSeats, tier.BasePrice, tier.Name)`

`per-token`:
- Find the input/cheapest token tier (non-opaque, BasePrice > 0)
- If none: CannotNormalize
- `NormalizedMonthlyCost = tier.BasePrice * (float64(RefTokensPerMonth) / 1_000_000.0)` — tier.BasePrice is price-per-1M-tokens
- `NormalizationAssumptions = fmt.Sprintf("%.0fK tokens/month at $%.4f per 1M tokens (tier: %s). Input cost only.", float64(RefTokensPerMonth)/1000, tier.BasePrice, tier.Name)`

`per-minute`:
- `NormalizedMonthlyCost = tier.BasePrice * RefMinutesPerMonth`
- `NormalizationAssumptions = fmt.Sprintf("%d minutes/month at $%.4f/minute (tier: %s).", RefMinutesPerMonth, tier.BasePrice, tier.Name)`

`credits`:
- Find credit pricing tier; if tier has cost-per-credit info:
  - `NormalizedMonthlyCost = tier.BasePrice * float64(RefTokensPerMonth) / 1_000_000.0`
  - `NormalizationAssumptions = "Credit-based pricing. Approximated as token-equivalent: 1M tokens/month at credit rate."`
- Else: `CannotNormalize=true, CannotNormalizeReason="Cannot normalize: credit-to-usage conversion not available on public page"`

`hybrid`:
- Find base fee tier + usage component
- Best-effort: use cheapest base tier + per-token/seat rate
- `NormalizationAssumptions = "Hybrid pricing: base fee + usage. Normalized using cheapest base tier and reference workload."`
- If structure unclear: CannotNormalize

`other` (and default fallback):
- `CannotNormalize=true`
- `CannotNormalizeReason="Cannot normalize: pricing model '" + data.PricingModel + "' cannot be mapped to a monthly cost"`
- Set `NormalizationAssumptions = "Raw pricing: " + summarizeTiers(data.Tiers)` — a helper that joins tier names and prices as a readable string

**Safety guards (Pitfall 4):**
- Before any multiplication: check `tier.BasePrice > 0`, else CannotNormalize
- Before accessing tiers: check `len(data.Tiers) > 0`
- If `!data.PricingPublic`: set `CannotNormalize=true, CannotNormalizeReason="Cannot normalize: all pricing is Contact Sales"` and return early

**Helper:** `summarizeTiers(tiers []Tier) string` — returns comma-joined "TierName: $price/unit" or "TierName: Contact Sales" strings.

func (db *GhostDB) SaveSnapshot(ctx context.Context, scanRunID, competitor, rawHTML string, fromCache bool) (int64, error) {
    var id int64
    err := db.pool.QueryRow(ctx,
        `INSERT INTO pricing_snapshots (scan_run_id, competitor, raw_html, from_cache, scraped_at)
         VALUES ($1, $2, $3, $4, NOW()) RETURNING id`,
        scanRunID, competitor, rawHTML, fromCache,
    ).Scan(&id)
    if err != nil {
        return 0, fmt.Errorf("SaveSnapshot %s: %w", competitor, err)
    }
    return id, nil
}
```

**Step 4 — Add SaveExtractedPricing method:**
```go
// SaveExtractedPricing updates a pricing_snapshots row with LLM-extracted and normalized data.
// snapshotID is the SERIAL id returned by SaveSnapshot.
func (db *GhostDB) SaveExtractedPricing(ctx context.Context, snapshotID int64, data *normalizer.RawPricingData) error {
    tiersJSON, err := json.Marshal(data.Tiers)
    if err != nil {
        tiersJSON = []byte("[]")
    }
    _, err = db.pool.Exec(ctx,
        `UPDATE pricing_snapshots SET
            pricing_model            = $1,
            tiers_json               = $2,
            normalized_monthly_cost  = $3,
            normalization_assumptions= $4,
            confidence               = $5,
            pricing_public           = $6,
            cannot_normalize         = $7,
            cannot_normalize_reason  = $8
         WHERE id = $9`,
        data.PricingModel,
        tiersJSON,
        data.NormalizedMonthlyCost,
        data.NormalizationAssumptions,
        data.Confidence,
        data.PricingPublic,
        data.CannotNormalize,
        data.CannotNormalizeReason,
        snapshotID,
    )
    if err != nil {
        return fmt.Errorf("SaveExtractedPricing snapshot %d: %w", snapshotID, err)
    }
    return nil
}
```

**Step 5 — Add SaveExtractionError method** for recording failures without crashing:

func (db *GhostDB) SaveExtractionError(ctx context.Context, snapshotID int64, extractionErr error) error {

        `UPDATE pricing_snapshots SET extraction_error = $1 WHERE id = $2`,
        extractionErr.Error(), snapshotID,
    )
    return err
}
